Web UI for gateways, devices, and tenants; integrations to clouds/DBs; gRPC and REST APIs so you can embed it. The project is a stack, not just the NS: Concentratord (SX130x / 2.4 GHz over ZeroMQ), MQTT Forwarder, Gateway Bridge (Semtech UDP Packet Forwarder or Basics Station), Gateway OS firmware, and a relay mesh that doesn’t require device changes.
