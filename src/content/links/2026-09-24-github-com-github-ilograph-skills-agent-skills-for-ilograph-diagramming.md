Official Ilograph agent skills for turning a codebase into interactive, auditable sequence diagrams. Install via Claude Code (`/plugin marketplace add ilograph/skills` then `/plugin install ilograph-skills`) or `npx skills add ilograph/skills`. `/generate-ilograph` analyzes the repo, asks which flows to diagram, and writes `ilograph.yaml` you paste into the Ilograph web, desktop, or Confluence apps. `/update-ilograph` refreshes the YAML and code citations in place.

Why it matters: nested, zoomable YAML diagrams with line-level code refs, so an agent can keep architecture pictures in sync with the repo instead of dumping throwaway Mermaid snapshots.
