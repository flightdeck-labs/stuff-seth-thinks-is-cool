summary: "OmniWM is a free, GPL-2.0 tiling window manager for macOS 26+ (Tahoe) on Apple Silicon. It ships both Niri-style scrolling columns and Hyprland-style dwindle BSP, plus a built-in Ghostty quake terminal, command palette, scratchpads, workspace bar, trackpad gestures, and `omniwmctl` IPC/CLI. Official builds are signed and notarized and do not require disabling SIP. Install with `brew install --cask omniwm` (v0.7.3 at capture).\n\nWhy it matters: if AeroSpace or yabai never quite felt like Niri/Hyprland, this is the closest Mac attempt — still early, and Tahoe/Apple Silicon only."
