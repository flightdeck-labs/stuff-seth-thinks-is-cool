God’s Eye View is an open-source, browser-based 3D globe that brings live aircraft, ships, satellites, earthquakes, public cameras, radio, and other public data layers into one inspectable interface. It is a useful reference for geospatial UI work: the project documents the practical tradeoffs around live-feed interpolation, keyless versus provider-backed layers, local credential handling, and a Cesium/Vite implementation. It runs locally without API keys for a meaningful baseline; optional keys add photorealistic terrain, map search, or voice control.

Why it matters: a concrete, unusually polished example of making public real-time data explorable rather than just displaying it on a map.
