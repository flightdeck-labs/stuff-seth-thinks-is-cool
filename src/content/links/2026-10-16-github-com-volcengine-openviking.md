summary: "OpenViking is Volcengine’s open-source context database for agents: knowledge, memory, and skills live as a virtual filesystem under `viking://`, so you (and the agent) can `ls` / `tree` / `read` / `grep` instead of stuffing a black-box vector store. Directories get generated L0/L1 summaries so the agent can skip full L2 content. Run a local server (`uv tool install openviking`) or use Volcengine’s hosted service; plugins cover Claude Code, Codex, Cursor, OpenCode, and friends. Their LoCoMo numbers claim native memory jumping from ~24–57% to ~80–83% with fewer tokens (they bench Hermes, OpenClaw, and Claude Code).\n\nWhy it matters: inspectable agent memory plus scoped retrieval, not just another embedding dump."
