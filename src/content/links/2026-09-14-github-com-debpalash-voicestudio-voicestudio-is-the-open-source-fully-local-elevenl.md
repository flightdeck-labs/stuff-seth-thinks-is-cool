VoiceStudio (formerly OmniVoice-Studio) is an AGPL-3.0 desktop studio that tries to cover ElevenLabs-style work fully locally: clone or design a voice, dub video, dictate, transcribe, and produce audiobooks/stories on your own machine. README claims 16 TTS engines, 11 ASR engines, a 646-language catalogue, Apple Silicon / CUDA / ROCm / CPU backends, plus a local REST/SSE/WebSocket API, OpenAI-compatible audio API, and an MCP server. No account or usage meter for the default local workflow; voices and projects stay on disk unless you opt into remote workers.

Why it matters: one place to try local cloning/dubbing without a hosted TTS subscription—if you have the hardware and can live with an active beta (Electron rewrite in progress; prefer the latest release over `main`).
