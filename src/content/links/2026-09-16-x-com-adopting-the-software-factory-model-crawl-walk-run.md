summary: "Zach Lloyd’s crawl/walk/run path from local coding agents to a cloud software factory. Crawl is one-off trigger→agent jobs (issue triage, PR review, Sentry debug, CI self-heal, docs, visual QA). Walk is standing up one full loop on a simple surface — triage → spec → implement → review → verify → ship → monitor — with humans as escape hatches; Warp says that loop already covers ~75% of changes to warp.dev. Run is scaling that onto harder repos with shared context, evals, multi-model/harness, data ownership, and factories-as-code.\n\nWhy it matters: a concrete adoption ladder, plus the useful warning that a pile of point automations won’t share context, metrics, or governance — the factory is the system, not a bigger agent."
